# QR Code Generator

A simple Python application that generates QR codes from text or URLs and saves them as PNG images.

This project is part of my Python Toolbox, a collection of practical projects developed to improve my Python skills through hands-on learning.

## Features

- Generate QR codes from text or URLs
- Validate empty user input
- Save QR codes as PNG images
- Display confirmation messages

## Technologies

- Python
- qrcode
- Pillow
- time (Python standard library)

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the application:

```bash
python main.py
```

Enter a text or URL when prompted.

The QR code will be saved as `qrcode.png`.
